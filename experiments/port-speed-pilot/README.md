# Bounded port-speed pilot

This experiment changes development infrastructure, not coverage. It does not
replace any existing proof contract or confer fresh node/Final qualification.
Existing material/compositor compilers remain the production implementation.

## Acceptance plan

1. Generate structural codecs and case inventories for two existing families
   from a reviewed descriptor. Exercise actual fixture packets and adversarial
   mutations. Native oracle equations and expected values remain independent.
2. Separate native-reference content keys from current-runtime acceptance.
   Demonstrate a runtime-only cache hit, native/settings misses and tamper
   rejection. Never reuse an old acceptance result as current acceptance.
3. Use pinned Blender shader-tool lowering and dependency metadata to attempt
   a closed procedural library bridge. Validate language conversion, native
   Three function integration and varying inputs. Record exact blockers and
   source licenses. Compilation alone is not numerical parity.
4. Run a small real saved-scene/current-runtime canary before large matrices.
   Keep type/hash/branch/ownership checks exact; prospective numeric contracts
   and scene appearance checks must be declared separately. Existing gates stay.

For each lane record setup/execution time, handwritten/generated files and
lines, failed attempts, scope and unresolved work. Textual size is not authoring
time. A speedup ratio requires comparable instrumented authoring work, which
the old pipeline did not record. Do not extrapolate one passing scene to a node
family or universal Blender semantics.

## Composition and correctness

The next useful coverage unit should be a whole graph corridor, such as image
source → domain/transform/filter → composite. A common schema cannot infer image
realization, hidden coordinate defaults, error amplification or resource effects.
Those need reviewed transfer rules and independent scene tests. Preserve the
separate live, constant-folded, baked and refused outcomes in every report.

Spreadsheet updates are weekly and at meaningful published batches. These
experimental results do not justify a coverage refresh.

## Contract and cache results

`../operator-contract-pilot` generates Python/TS codecs and case inventories for
Int3 and finite ImageInfo. Root replay passed nine tests, accepted 37 archived
native programs, rejected 32 structural mutations and checked 9,472 historical
words. Existing semantic validators remain authoritative. The 260 handwritten
executable lines and 50 generated physical lines do not demonstrate a net
reduction yet: old implementations remain and fixtures dominate added files.

`../port-stage-cache-pilot` passed five additional tests and an independent root
replay on its matching published SDK. Native/reference/settings changes miss;
tampered content refuses. Cache-only verification was about 5.7 ms in the
original observation, excluding about 266 ms of native-input integrity checks.
Final acceptance always remains fresh. A root replay on this newer candidate
correctly refused changed `static-switch-family/reference.py` source bytes;
the finite-ImageInfo addition had changed the conservative native source key.
The importer was not weakened to accept that mismatch.

Root logs: `/tmp/scenetoweb-speed-combined-tests.log` (14 tests),
`/tmp/scenetoweb-pilot-contract-replay-root.log`,
`/tmp/scenetoweb-port-stage-cache-root-replay-matched.json` and the retained
mismatch `/tmp/scenetoweb-port-stage-cache-root-replay.log`.

## Shader bridge result

`../shader-kernel-bridge-pilot` uses pinned Blender canonical lowering, macro
preprocessing and Naga to emit WGSL and GLSL ES300 for Gradient, Checker and
White Noise. No kernel-body arithmetic was rewritten. One-time shader-tool
build: about 24.6 seconds; observed three-library generation/validation after
setup: 0.188 seconds. This excludes installation and authoring time.

All 64 small draws compiled on Metal/SwiftShader with WebGPU and WebGL2. Exact
fragment-coordinate calibration passed; 14,336 output words had zero GLSL/WGSL
differences. Analytic Checker and split-hash integer checks passed. The declared
float gate **failed**, with 16 radial-Gradient values above 8 ULP (maximum 16),
despite maximum absolute error 5.96e-8. Other tested float cases passed. The gate
was retained, and the result earns no numerical, Blender-parity or node support
credit. Largest captured fragment shaders: 24,676 bytes WGSL /27,056 bytes ES.

Root independently replayed the reader; `/tmp/shader-bridge-root-reader.json`
was byte-identical to the archived failed closure. Earlier UV-interpolation and
desktop-GLSL numeric-promotion failures remain retained. These identified
reusable fixture/backend fixes rather than requiring per-kernel patches.

The bridge merits a next pilot on Noise/Voronoi with independent native EEVEE
references, explicit input/context adapters, reviewed precision profiles and
runtime performance measurements. Source licenses must accompany generated
artifacts. This experiment does not ship kernels in the production SDK.
