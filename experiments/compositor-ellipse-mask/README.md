# Pinned CPU Ellipse Mask — qualified bounded generator

The [fresh root receipt](evidence.json) qualifies a **partial Blender5.3 CPU
compositor slice**:108 native graphs,16 actual saved Final scenes,496 browser
case-runs and235,856 primary Float32 words with0 word differences or contract
violations. Both actual WebGPU/WebGL2 APIs pass on observed Metal and SwiftShader.
Separate checks cover144 resize/DPR frames,192 Final lifecycle cycles and17
actual Python cache prefixes. The141-input source inventory closes runtime
fingerprint `819e83b39bd016d505507cebfc1dff6c47e343669dc2d9f6126dee7d65955499`.

This is a static, axis-aligned literal generator, with at most one varying row
table and a closed texture-free pointwise compositor-kind set. Render Layers,
Images, curves/ramps and spatial consumers are excluded. Combined row/display
lookups are limited to8; extra post-LDR registrations refuse. General artist
scene-compositing graphs, EEVEE shader/material behavior, native GPU evaluation,
fields, animation, rotation, other Blender versions/builds/hosts and whole-scene
appearance remain unqualified. Historical prototypes are not reused as proof.

The immutable case manifest contains108 native cases and16 actual saved Final
sources: the87 original CPU prototype settings (including eight separate-vs-FMA
controls), plus default/allzero/equal-value/zero-identity resize families, DPR2,
portrait, larger/smaller physical extents, and group/reroute normal/identity
routes. Zero-Size scalar identities are distinguished from equal-valued nonzero
fields with `expectedSingle`, checked against actual emitted native metadata.
ImageInfo scheduling research remains separate; no new ImageInfo input is
admitted here.

`reference.py` creates actual authored native Ellipse nodes and renders them
through CyclesCPU + compositorCPU, with native Float32 EXR output. The independent
readback control is an asymmetric image copy. The fixture records source
preservation, raw scalar copy checks and explicit refusals; it never overwrites
the operator implementation or inserts a golden mask into the native graph.
All case settings are read back to reject silently clamped test inputs.

`capture.mjs` uses the shared fresh-cache-prefix launcher, saves the selected
owned native scenes, publishes them through the built SDK and archives actual
native invocations and source bytes. Every selected source must remain unchanged.
`run.mjs` snapshots the actual built runtime/vendor closure and all imported
browser fixture files. `browser-contract.mjs` is a real, captured shared negative
contract, not an unpinned helper. The source/fixture inventory is explicit in
`fixture-files.json`; adding an imported helper requires adding its pin.

Actual browser checks cover both APIs on Metal and software profiles, independent
Float32 copy/orientation calibration, first draw and subsequent animation frames,
all primary native pixels, invalid→valid extent recovery, larger/smaller/DPR
changes, immutable source IR, fixed RG32I table identity/version/data on rejected
resizes, declared row resource counts, no added RTT/pass, and repeated actual
Final installation/disposal restoring exact authored material/callback identities
and the independently observed renderer baseline. Zero/constant outputs must
retain their result guard after shader compilation.

The independent closed reader checks native/case/source pins, actual source
class/identity facts, saved source/GLB/manifest/presentation bytes, launch archives,
closed native/Final/browser/refusal censuses, actual API/profile identity, fresh
current compiler provenance and immutable runtime/vendor/fixture archives.
Exact Float32 words are required; no epsilon or output repair is permitted.
No native GPU-authored, rotation, field-input, spatial-domain or AA claim is
made. The first resource slice admits at most one varying row table; constants,
equal-value and zero-Size nodes consume0. Other compositor texture producers
are excluded by a closed pointwise-kind list. Combined row plus display LUT
lookups are limited to8, and additional post-LDR registrations require separate
sampler accounting. The browser negative checks the first invalid2-table graph
before allocation. Production unit/native controls cover7/8 display LUT
boundaries; those are admission checks, not new display-color numerical proof.

## Run after the shared production build freezes

Use Node24 and a new directory. The matrix serializes native capture, actual
Final publication, Metal raw/Final, software raw/Final and the closed reader:

```sh
node --test scripts/lib/browser-proof-contract.test.mjs experiments/compositor-ellipse-mask/protocol.test.mjs
node experiments/compositor-ellipse-mask/matrix.mjs artifacts/verification-ellipse-root-fresh
```

The matrix preflights its parsed runner/reader contract before creating output
or invoking Blender. It does not rebuild production. For staged execution:

```sh
node experiments/compositor-ellipse-mask/capture.mjs CPU artifacts/verification-ellipse-root-fresh/cpu
SCENETOWEB_ELLIPSE_MASK_REFERENCES=artifacts/verification-ellipse-root-fresh/cpu BLENDLINK_TEST_PROFILE=metal BLENDLINK_TEST_CHROMIUM_CHANNEL=chromium node experiments/compositor-ellipse-mask/run.mjs --built
SCENETOWEB_ELLIPSE_MASK_REFERENCES=artifacts/verification-ellipse-root-fresh/cpu BLENDLINK_TEST_PROFILE=metal BLENDLINK_TEST_CHROMIUM_CHANNEL=chromium node experiments/compositor-ellipse-mask/run.mjs --built --final
node experiments/compositor-ellipse-mask/verify.mjs artifacts/verification-ellipse-root-fresh artifacts/verification-ellipse-root-fresh/qualified.json
```

Run the software stages with the matrix's explicit SwiftShader flags as well
before the reader; staged Metal commands alone cannot qualify the family.
Retain failed directories and use a new directory after fixture/source changes.
