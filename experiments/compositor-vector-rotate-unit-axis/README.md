# Exact signed unit-axis Vector Rotate candidate

This extends the independently qualified CPU fixed-axis compositor mechanism to native `AXIS_ANGLE` with exactly one `+1` or `-1` Axis component and positive zero in the other two components. Native Blender 5.3 defaults are `AXIS_ANGLE`, Axis `[0,0,1]`, and Angle positive zero. Arbitrary axes, zero axes, linked/computed axes, negative-zero/subnormal Axis storage, and Euler mode remain refused. No capability promotion or numerical browser qualification is recorded here.

The pinned `node_shader_vector_rotate.cc` uses the same `sh_node_vector_rotate_around_axis` for Axis Angle and fixed X/Y/Z modes: ordered Float32 subtraction of Center, `axis_angle_to_mat3`, `mul_m3_v3`, then recenter. Invert negates Angle. `normalize_v3_v3_length` computes dot, square root, reciprocal and multiplication; for an exact signed unit axis these values are exactly one and the source axis is preserved. This is a source argument for the six admitted values, not evidence about arbitrary-axis normalization.

The original Axis Angle mode and raw Axis words are retained in a distinct model/profile. The source cache includes Axis words; they are reread before publication and at extraction closure. The owned native 35-node MF basis carrier copies Axis raw words and snapshots active Axis storage. Geometry fixed modes do not expose an Axis socket, so the private snapshot deliberately reads it only in Axis Angle mode. Captured normal coefficients, pre-store hashes, structural unit/sin/cos shape, effective sine sign and the existing bounds remain required.

Signed unit axes can change the signs of internal zero matrix coefficients. Basis output hashes do not expose those internal signs. The existing bounded proof still applies: admitted Vector/Center values lie on the `2^-39` lattice; nonzero coefficients are at least `2^-63`, giving product/sum quantum at least `2^-125`. No nonzero intermediate can be subnormal, and the final positive-zero or normal Center makes hidden zero coefficient signs unobservable. No coefficient snapping, output repair, angle quantization, or tolerance change is used.

The GPU staged matvec/recenter builder, private Normalized rows, row owner, before-render producer scheduling, renderer epoch and target/binding guards are unchanged. The old fixed-axis model refuses the new Axis property; Axis Angle must use the distinct new model and profile. The earlier shader implementation and current joint SDK are untouched.

The owned CPU-only research captured 72 signed-axis / Invert / Angle keys and 648 Geometry evaluations. Independent JS replay checked 648 component predictions, 648 corresponding fixed-mode native twin component words, and all pre-store hashes, with zero differences. Ordinary, bounds and centered vectors cover Angle positive zero, minimum/next-minimum, ordinary, and signed maximum values. This is neither a CPU compositor render nor a saved Final/browser proof. The full captured reports and guarded archives remain ignored local artifacts; [research-evidence.json](./research-evidence.json) pins them compactly.
