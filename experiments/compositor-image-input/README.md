# Native static compositor Image input

The bounded live port reads authored **static Image/Alpha inputs** rather than
capturing a rendered compositor result. Packed/file sRGB PNGs and generated
sRGB byte buffers use a private native image-only normalization. Generated
Linear Rec.709/Non-Color float buffers retain their direct Float32 values.
No scene render, surface bake, artist node rewrite, or source-image save is
part of production extraction.

Input normalization uses different byte and float models. A universal
`Image.save_render` conversion is incorrect: native byte Linear Rec.709,
legacy data/alpha cases, and float-tagged sRGB can disagree with that route.
Only the measured combinations enter this model. Image filepath, format,
color space, alpha mode, dirty pixels, packed bytes and users remain unchanged;
owned decoder scenes/images are removed on success and failure.

## Canvas and resize contract

An Image has its own finite pixel canvas. It is **not stretched to the render
viewport**. Pointwise processing runs on that native canvas; only afterward is
it centered, cropped or transparently padded into the live drawing buffer.
Padding before an Invert/Exposure node would change the authored result.

Modern CPU realization retains Blender's Float32 matrix/coordinate stages,
parity correction and independently rounded bilinear neighbor indices. Simple
integer centering misses measured odd-window edge behavior. The source window
and textures remain fixed while resize updates bounded coordinate tables and
uniforms. Repeated sizes do not reupload those tables or change shaders.

Blender 4.2 currently requires even source and drawing-buffer dimensions.
Investigated odd legacy windows had unqualified/corrupt native results.
An unsupported resize raises a named limitation, preserves caller MRT/target/
clear state, and can recover at the next valid extent without rebuilding.
The retained Image corpus uses the default legacy Composite Use Alpha setting;
terminal output-alpha policy belongs after finite-window realization.

## Limits

- Source compositor device CPU; browser renderer WebGPURenderer with WebGPU or
  WebGL2. This does not qualify Blender's GPU viewport compositor or ordinary
  WebGLRenderer post processing.
- Bundled OCIO configuration with Linear Rec.709 working space. Custom input
  processing and unknown input transforms refuse.
- RGB/RGBA static, single-view, single-layer inputs. File/packed byte input
  currently requires PNG/sRGB. Generated byte input requires sRGB and Straight
  or Premultiplied alpha. Generated float input requires Linear Rec.709 or
  Non-Color/Raw; authored signed/HDR RGBA is retained.
- At most 4 megapixels per image, 8 megapixels of distinct decoded images per
  program, source dimensions <=4096 and output dimensions within 1..8192.
- Image/Alpha share one deduplicated input allocation. Native Float32 input
  values are losslessly zlib/base64 encoded inside the pinned presentation
  asset; Three's existing MIT fflate decoder adds no artist installation step.
  Decoded length/checksum/finite values and ownership are checked.
- Direct outputs and supported pointwise consumers can use matching image
  canvases. Mixed Render Layers, different image canvases, neighborhood filters,
  transforms, render borders/crop, sequences/movies/UDIM, image/node animation,
  multiview, multilayer and file-float display windows remain named refusals.

## Earned evidence

The durable native fixture produces **95 graphs on 4.2 and 97 each on 5.2/5.3**:
289 graph cases / 329 actual reference frames. It measures Image/Alpha,
file/packed/generated sources, RGB/RGBA PNGs, unsaved painted file/packed
buffers, alpha modes, signed/HDR float values, a losslessly compressed 1080p
background, pointwise grading and shared Image/Alpha use. Resize cases retain
one compositor through odd/even sizes, DPR 2, repeated extents and legacy
rejection/recovery, checking caller state and stable shader structure.

The built SDK passes **1,156 graph checks / 1,316 positive output-frame checks**
across recorded Apple M5 Pro Metal and LLVM SwiftShader, each using WebGPU and
WebGL2. Maximum absolute error is 2.384185791015625e-7 against the unchanged
2e-5 budget. The copied installed-package probe extracts an actual pinned
packed-image payload under a package-qualified namespace and verifies its
decoded size/digest and equality with canonical extraction on all three
versions. Source and fixture hashes accompany native references.

The separate Final fixture saves a real packed-PNG Blender scene. Production
Final sync publishes its GLB and presentation, verifies pins, preserves the
`.blend` bytes and matches the independently rendered native input. Browser
proof loads that exact GLB and pinned presentation through the production post
pipeline, including the display transform, and rejects a bad presentation pin.
All three native versions pass both recorded adapters/backends; the largest
Final pixel difference is 5.960464477539063e-8.

This is a partial input/canvas port, not universal image formats, working spaces,
video playback, mip/transform coverage or whole-renderer appearance parity.

## Reproduce

Use a built worker and an actual Blender executable:

```sh
npm run build
BLENDLINK_COMPOSITOR_IMAGE_REFERENCES="$PWD/artifacts/image/cpu" \
  /path/to/blender --background --factory-startup --python-exit-code 1 \
  --python packages/blender-addon/tests/compositor_image_check.py
node experiments/native-compositor-differential/run.mjs --built \
  --out artifacts/image/browser artifacts/image/cpu
```

Repeat native generation for 4.2/5.2/5.3 and pass all reference directories to
the browser runner. Repeat playback with
`BLENDLINK_TEST_CHROMIUM_CHANNEL=chromium`; verify the recorded adapter.
Default native success sentinel: `BLENDLINK_COMPOSITOR_IMAGE_PASSED`.
The positive source family is CPU-only; GPU refusal is tested inside it.

For actual Final publication/pipeline proof:

```sh
export BLENDLINK_COMPOSITOR_IMAGE_FINAL="$PWD/artifacts/image/final"
export BLENDLINK_COMPOSITOR_IMAGE_BLENDER=/path/to/blender
"$BLENDLINK_COMPOSITOR_IMAGE_BLENDER" --background --factory-startup \
  --python-exit-code 1 --python experiments/compositor-image-input/final_scene.py
BLENDLINK_COMPOSITOR_IMAGE_BUILT=1 node packages/blendlink/scripts/run-vitest.mjs \
  experiments/compositor-image-input/export.test.ts
node experiments/compositor-image-input/run.mjs --built
```
