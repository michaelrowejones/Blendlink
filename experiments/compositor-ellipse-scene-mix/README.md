## Arithmetic, ownership and cost

A GPU endpoint selection is insufficient even for exact binary factors. Native CPU Mix evaluates `(1-f)*A + f*B`, including zero-weight exceptional operands. The source-pinned, bit-classified binary implementation reproduces the bounded native zero, infinity and NaN rules without evaluating GPU floating Mix algebra. The retained exhaustive HalfFloat prototype covers all 65,536 uploaded encodings in each RGBA channel, both factors and both operand directions on both observed APIs: 3,145,728 words, zero differences. Actual decoded GPU words—not a NumPy HalfFloat decoder—were supplied to native CPU Image references. Separate signed/payload F32 NaN controls and actual rendered ScenePass attachment controls are retained as pilot observations; they do not replace this family's integrated Final proof.

Decoder calibration runs once per actual renderer/device/context allocation epoch. Concurrent preparations share it; cancellation detaches a caller. Its temporary draw/readback state is restored before waiting, allowing an existing pipeline to keep rendering. Owned texture, target, framebuffer, fence and staging allocations close on success, failure, cancellation completion, context/device loss and renderer disposal. A previously saved original dispose is detected by the allocation epoch; captured physical handles supply cleanup if the old manager was reset. Replacing an intact manager preserves its original disposal ownership. The cache contains no calibration GPU resources after completion. No per-frame readback or payload `finiteScene` flag exists.

Nominal transient calibration storage is 4 MiB, excluding driver/compiler caches and implementation overhead. Observed pilot calibration was about 133 ms WebGPU / 67 ms WebGL2 with cold driver shader caches, and 11 / 14 ms on a later run with those caches warm. These are local observations, not steady-state rendering or export-latency measurements. Warm certificate reuse submits no calibration draw. The existing Ellipse row table remains fixed at 64 KiB; per-frame boundary preparation is O(W + H log W), with no CPU full-pixel mask generation. The scene color attachment is an ordinary full-frame HalfFloat image; this feature does not remove scene rendering cost.

4. Reload/redraw the saved scene and require an identical independent baseline. Require exact native words for both the direct production compositor and the **actual installed Final pipeline's pre-display compositor node**, sampled only by the proof into an owned Float32 target after each actual Final render. Raw display is a separate audit: record all word differences, maximum ULP, unclamped absolute error, and clamped absolute error, with exact alpha and nonfinite classes; finite zero/underflow differences are counted and exemplified.
