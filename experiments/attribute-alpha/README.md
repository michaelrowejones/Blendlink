# Qualified named Geometry Attribute Alpha

The full root matrix qualified the narrow Blender 5.3 `ShaderNodeAttribute` GEOMETRY Alpha route from explicit nonempty named FLOAT_COLOR POINT/CORNER layers. Nine authored scenes passed actual native EEVEE, raw transport, normal authored Meshopt Final publication, and raw/Final browser stages on both actual APIs and observed Metal/SwiftShader profiles. Raw stored alpha and actual indexed position/corner/material associations remain exact Float32 before and after default authored Meshopt optimization. RGB comparison uses native EEVEE's half-film output in an EXR32 container; it permits the predeclared absolute bound on every pixel, including seams and edges. The large RGB word-difference count is measured and retained. This is not a word-exact F32 raster claim. Output alpha-one equality is checked separately.

The implementation reuses the existing `vertex_color_alpha` opcode/model, private scalar carrier, optimizer and runtime binding, adding no new browser kernel, texture, pass or per-frame native work. The shared [Vertex Alpha harness](../vertex-color-alpha/README.md) selects real native Attribute nodes through nine explicit definitions, including groups/reroutes, shared owners/materials, RGB preservation and the special lowercase `color` surface-Mesh control. Its original eight Vertex Color definitions remain the default and retain their own evidence.

An unrelated active/render layer distinguishes explicit named lookup. The source emitter refuses empty names and exact lowercase `temperature`; the latter has a retained native counterexample because Blender forces Attribute Alpha to one. The owned installer requires a present FLOAT_COLOR POINT/CORNER layer and bounded static primary surface Mesh, with raw +0/normal [0,1] alpha, no deformation/instances/animation and unambiguous material/corner bindings. BYTE_COLOR, other domains and non-GEOMETRY Attribute Alpha have no new support. Lowercase `color` is supported only in the surface Mesh slice; volume behavior remains excluded.

This field proof does not qualify explicit opacity, transparent coverage, Color+Alpha opacity, whole-scene lighting/cameras or cross-engine PBR appearance. The exact immutable receipt retains its original phrase about opacity plus nonunit COLOR_0 refusing. That applies to untagged programs; the subsequently integrated source-certified scalar-replacement adapter has an independent scope and is not qualified by this field matrix.
