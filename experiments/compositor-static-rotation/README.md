# CPU static Quaternion / Rotation proof

This family tests a Blender 5.3 CPU compositor island: explicit linked Quaternion to Rotation followed by Rotation to Quaternion. Each literal component is raw positive zero or has magnitude between 2^-16 and 4. Native normalization stays inside a private Geometry Nodes CPU multi-function carrier; ROTATION never enters the runtime. Terminal components use existing VALUE constants. Source group bindings, reroutes and qualified static Float literal selectors are covered. Computed/recombined components, unlinked Euler-backed Rotation defaults, implicit casts, fields, GPU-authored compositor sources, shader contexts and Quaternion-to-Matrix chains are refused.

The 72 native graphs cover 36 quaternion settings, all four components, signed/scaled bases, zero identity, five non-half controls and five topology routes. Twelve unchanged saved scenes are exported through the built SDK. The fresh post-stable-ID root transaction qualifies both actual WebGPU and WebGL2 on Metal and SwiftShader: 336 browser cases, 21,504 primary Float32 words, 48 resize/DPR frames and 144 Final apply/dispose cycles. Every accepted comparison is exact uint32 equality, including positive zeros; no tolerance or output repair applies. Geometry MF results are independently compared to actual CPU compositor EXR32 pixels. Basis and zero identity additionally use manual raw-word goldens.

The matrix does not build. Its caller must freeze and build the combined source first. `capture.mjs CPU <fresh-directory>` performs the policy check, all 72 native CPU renders and all 12 saved Final exports once. The four browser contexts follow serially, then `verify.mjs` closes raw pixel derivation, exact case census, current native source closure, saved scene bytes, guarded launcher identities/fresh Python prefixes, independent current built-runtime emission, fixture/vendor/maps and ownership receipts. Invalid runtime ROTATION transport and unavailable actual WebGPU adapter controls must refuse.

Normalization is performed by unchanged native callbacks, not translated arithmetic. With nonzero component magnitudes at least 2^-16 and at most 4, nonzero squared norm is at least 2^-32 and at most 64; bounded nonzero normalized components remain normal. Raw outputs are independently checked before decoding, so unexpected negative zero, subnormal or nonfinite words refuse. Signed bases demonstrate the absence of implicit quaternion sign canonicalization. Source values, topology and instance bindings are rechecked around the private carrier; its fixed eight nodes produce four endpoints once per island and leave no authored-data changes. The reviewed Matrix copy-only language remains unchanged and refuses Quaternion-derived inputs.
