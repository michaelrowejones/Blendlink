## Recommendation

Credit this **audited bounded color-program slice** under the user-approved
artist-visible standard, subject to root's admission review. Do not advertise
all BOX modes, arbitrary color graphs or the original material/scene as supported.
I found no remaining operational bug in the tested route, but the **current
source guard is wider than this visual evidence**:

1. `box_image_ir.emit` permits any linked vector accepted by the general emitter.
   This proof observes Object coordinates→Mapping(TEXTURE), scale2.5 with zero
   location/rotation. It does not qualify arbitrary procedural/nonlinear vectors,
   transformed coordinate ranges or their derivative behavior on all four GPUs.
2. The guard admits any saved1024-square opaque RGB8 sRGB PNG meeting metadata
   requirements. Native per-image mip extraction and integrity checks are strong
   input/storage contracts, but they do not themselves prove a one-display-code
   cross-GPU bound for arbitrary pixel patterns. This visual proof uses the one
   original Plaster image (PNG SHA676813f1…3452, decoded RGBA SHAaa48124e…fd78).
   Earlier sampler controls are useful retained evidence, not a four-GPU proof of
   every arbitrary image. No cause such as anisotropy is inferred from this gap.
3. `validate_channels` enforces BaseColor-only use of the fresh operation, direct
   Principled, opaque Alpha1, all five core programs and zero refusals, but does
   not constrain the complete BaseColor graph to this tested LDR composition or
   prove its output range. Arbitrary downstream graphs can exceed0..1; the
   Standard-sRGB LDR observation profile deliberately refuses HDR instead of
   clipping it. Individually supported nodes do not make this receipt evidence
   for every new composition.

For a source-fenced first production slice, require the audited image/data and
vector/color composition (or an equally explicit validated input contract) and
retain the current format/engine/build/normal-storage/anisotropy/opaque/NoSkip
guards. The exact BaseColor IR in all three Finals hashes to

until its general image/vector/color domain is explicitly qualified. A metadata
description alone would not narrow what the current emitter actually admits.
No guard change or support promotion is made by this review.

## Root review decision

The independent root replay matches the exact close above. The captured source
program meets the frozen visual criterion, with strict failures retained.
The broader default source route remains experimental: no asset-name whitelist
or format-wide support is introduced by this checkpoint. A broader, held-out
image/vector gallery is the next admission task; it should include LDR endpoints,
asymmetric patterns, high-frequency minification and the intended coordinate
contracts before a general artist-facing route is enabled. The original Plaster
NormalMap and complete original scene remain separate tasks.

Pure CPU visual, canonical-readback, geometry-ownership and fixed-origin controls
are now part of `npm run test:node-pipeline`, so future changes exercise these
contracts automatically without native GPU work. Frozen hardware evidence is
still replayed and qualified separately.
