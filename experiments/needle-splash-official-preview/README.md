# Needle Splash official Preview fixture

This is a narrowly bounded, coherent Needle **Preview** integration for the
Blender 4 Splash selected-sky fixture. It uses the package declarations and
official Vite configuration generated by Needle Blender add-on `1.4.2`, a clean
installed package tree, `@needle-tools/engine` `5.1.4`, Vite `8.0.3`, and the
exact uncompressed add-on export.

It does not prove Needle's licensed production transform. The development build
explicitly skipped the authenticated `@needle-tools/gltf-build-pipeline`
`3.0.0` production path because no valid Needle JWT was available. Production
compression, progressive delivery, and transform-time material changes remain
pending.

The broad repository inventory deliberately remains
`integration=mixed-source`. This one fixture is recorded separately as
`integration:splash-official-preview=coherent` so its evidence cannot promote
historical or unrelated package paths.

## What passed

- `npm ls --all` returned exit code `0` for this fixture.
- The official Needle Vite plugin completed a development build.
- Chrome loaded the page, `scene.glb`, and `forest.exr` over HTTPS.
- Needle reported Engine `5.1.4`, completed loading, selected the authored
  camera, and rendered a nonblank 1200 by 600 WebGL2 Canvas.
- The browser evidence has no page errors, request failures, HTTP errors, or
  relevant console errors.
- The screenshot is byte-identical to the earlier mixed-host capture. Changing
  to the clean official Preview host therefore does not change the established
  Splash visual conclusion.

Needle logged non-fatal warnings for several `MeshRenderer` components whose
mesh/material could not be retrieved, plus the expected commercial-license
logo warning. Those warnings are retained verbatim in the browser evidence.

The Eevee-relative differential is intentionally red: Needle still fails the
complete shadow, sky, and building-surface gates. A passed browser smoke gate
proves that the named stack loaded and rendered; it does not prove visual
parity.

## Reproduce

From this directory:

```powershell
npm.cmd ci `
  --cache ..\needle-coherent-addon-1.4.2\.npm-cache `
  --prefer-offline `
  --no-audit `
  --no-fund
npm.cmd ls --all
npm.cmd run build
```

The build is the official Preview/development path. Do not add `--production`
without a valid Needle license token and a separate evidence record.

From the Blendlink repository root, capture the official fixture:

```powershell
node artifacts\release-dogfood\blender-4-splash\needle-three-way-2026\capture.mjs `
  C:\Users\micha\Documents\GitHub\MichaelRoweJonesSite `
  'C:\Program Files\Google\Chrome\Application\chrome.exe' `
  authored-camera-official-preview-networked `
  C:\Users\micha\Documents\GitHub\blendlink\experiments\needle-splash-official-preview `
  https
```

Then rerun the fixture-specific visual gate:

```powershell
node experiments\splash-visual-fidelity-differential\run.mjs `
  --candidate experiments\needle-splash-official-preview\browser-evidence-needle-blender-4-splash-selected-sky-authored-camera-official-preview-networked.png `
  --output experiments\needle-splash-official-preview\visual-gates
```

The second command exits nonzero while the three visual gaps remain. Its
isolated negative controls must pass.
