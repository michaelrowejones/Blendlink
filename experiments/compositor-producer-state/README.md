# Borrowed compositor producer state research

Zero support or numerical qualification credit. SDK candidates schedule actual FRAME PassNodes using the actual NodeFrame cache before the owned RTT resets renderer state. Explicit domain roots serve Displace/affine/Crop; bounded serialized IR ancestry serves wrapped Relative Blur. No arbitrary TSL walk, private cache writes, sampling-law change, or copied reset state is used. A failed producer render restores renderer and PassNode temporary fields and rethrows; the next frame retries through the native cache.

The independent state-only browser control passed all four actual Metal/SwiftShader WebGPU/WebGL2 tuples: 40 controls across integer/fractional/affine/Crop/wrapped Blur and transparent/custom-clear plus a forwarding render hook. Every first PassNode draw observed caller clear color/alpha, tone/exposure and hook, rendered once per FRAME, and restored caller state. The separate public default-sampler copy matched 3,744 words. This is a state/ownership control, not a native Displace sampling oracle.

Retained r1/r2 failures compared the default linear copy against integer texel loads. Software produced 72 tiny edge words, including alpha 7.152557e-7 rather than zero. Those failures remain unchanged. The corrected state-only reference explicitly tests the public default sampler and grants no sampling credit.

A separate retained-native nearest-origin 13×9 actual Final check confirmed a real Displace precision failure after the state fix: 94 words on software WebGPU and 73 on software WebGL2. The actual scene-pass input still matched the original retained baseline. The narrow Displace-only provider fix clones a texel load before the RTT, preserving the original PassTexture/passNode and leaving the borrowed sampler/UV/reference/value unchanged. The original unchanged native oracle then passed on all four tuples: 13,104 direct/installed/repeated RGBA words, three installation cycles per tuple, plus 11,232 separately gated display words. No new native renders or Final exports occurred; the old source/Final/native packet was reused only as zero-credit diagnostic input. Full fresh qualification remains required.
